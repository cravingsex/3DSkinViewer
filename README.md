# SkinViewer

SkinViewer is a client-side Fabric mod for Minecraft 26.2. It renders the local player's live 3D skin in the title and pause menus, and displays the local player's name above their head in third-person view.

## Installation

Install Fabric Loader for Minecraft 26.2, place this JAR and Fabric API in the `mods` folder, then launch the Fabric profile. Mod Menu is optional.

## Settings

The configuration file is created at `config/skinviewer.json`. It provides `Show Name` and `Position` (`LEFT` or `RIGHT`).
